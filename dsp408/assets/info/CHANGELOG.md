# Historia wydań

## 0.9.1 — 2026-10-19

- Pakiety Windows oraz macOS Apple Silicon; obsługa USB HID i Ethernet na obu systemach.
- Edycja konfiguracji offline, import i eksport PRS z FIR oraz kopie banku presetów.
- Linkowanie kanałów, kopiowanie wybranych ustawień i czytelne oznaczenia grup.
- Usprawnienia wykresów PEQ, crossovera, kompresora i limitera oraz obsługi faderów.
- Osobny bypass i kasowanie FIR, nazwy filtrów oraz obsługa FIR w grupach Link.
- Wybór źródła Analog/AES dla wejść A–B; C–D pozostają analogowe.
- Przeliczanie opóźnienia na odległość z uwzględnieniem temperatury i opcjonalnie wilgotności oraz ciśnienia.
- Wybór One Time / Permanent podczas odblokowania DSP i oddzielna blokada edycji offline.
- Instalator Windows z aktualizacją, niezależną drugą kopią, deinstalacją i kontrolą otwartej aplikacji.
- Jasny i ciemny motyw, menu Help, informacje o licencjach oraz diagnostyka do schowka.
- Poprawki zapisywania plików, responsywności i obsługi okien dialogowych.
